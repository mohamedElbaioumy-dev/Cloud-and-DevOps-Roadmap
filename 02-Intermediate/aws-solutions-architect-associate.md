# AWS Solutions Architect - Associate
> **Description:** This section focuses on cloud architecture and solution design on AWS. You will learn how to select the right services, design secure, scalable, resilient, and cost-effective systems, and build architectures based on real-world requirements and AWS best practices. In addition, it provides the knowledge and architectural mindset required to successfully prepare for the AWS Certified Solutions Architect – Associate (SAA-C03) certification.
